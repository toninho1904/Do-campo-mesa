# 🌾 Do Campo à Mesa - Receitas Rurais Autênticas

Um site moderno e responsivo dedicado a receitas tradicionais do campo, feito com ingredientes naturais e frescos, sem produtos industrializados.

## 📋 Características

### ✨ Funcionalidades Principais

- **Banner Inicial Atraente**: Apresentação visual impactante com o nome do site e chamada para ação
- **Seção Sobre**: Explicação do propósito e filosofia do site
- **Categorias de Receitas**: 
  - 🍰 **Doces**: Bolos, massas doces, pães de queijo e mais
  - 🍲 **Salgados**: Polenta, massas, pães integrais e pratos tradicionais
- **Modal de Receitas**: Ao clicar em uma receita, abre um modal com:
  - Ingredientes completos
  - Origem de cada ingrediente (onde obter)
  - Modo de preparo detalhado
  - Tempo de preparo
  - Dicas e truques da casa
- **Seção de Benefícios**: Por que fazer receitas caseiras e naturais
- **Design Rústico**: Cores e estilo inspirados no ambiente rural
- **Responsivo**: Funciona perfeitamente em computadores, tablets e celulares

## 🎨 Design

O site utiliza uma paleta de cores rústica e natural:
- Marrom (#8B4513) - Cor principal
- Bege/Trigo (#D2B48C) - Cor secundária
- Dourado (#DAA520) - Destaque e botões
- Verde (#6B8E23) - Detalhes naturais
- Creme (#FFF8DC) - Fundo principal

## 🚀 Como Usar

1. **Abrir o site**: Simplesmente abra o arquivo `index.html` em um navegador web
2. **Navegar**: Use a barra de navegação para ir direto para as seções desejadas
3. **Explorar Receitas**: 
   - Clique na aba "Doces" ou "Salgados"
   - Clique em qualquer receita para ver os detalhes
   - Leia sobre os ingredientes e sua origem
4. **Fechar Modal**: Clique no X ou fora do modal, ou pressione ESC

## 🔧 Como Customizar

### Adicionar Novas Receitas
Edite o arquivo `script.js` e adicione uma nova entrada no objeto `receitas`:

```javascript
13: {
    titulo: "Sua Receita",
    tipo: "doce", // ou "salgado"
    ingredientes: [...],
    origem: [...],
    modo_preparo: [...],
    tempo: "tempo estimado",
    dica: "sua dica"
}
```

### Alterar Cores
Modifique as variáveis CSS no início do arquivo `styles.css`:

```css
:root {
    --cor-principal: #8B4513;
    --cor-secundaria: #D2B48C;
    /* ... */
}
```
